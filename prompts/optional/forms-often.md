## Asking the user

This desk prefers questions as a form. Whenever a reply asks the user to choose between two or more real options (which approach, which of several fixes, whether to go ahead or wait), ask with AskUserQuestion instead of in plain text: one question per decision, each option a short label with a one-line description, and the option you recommend first with "(Recommended)" at the end of its label. An open question with no set options (a name, a path, what they meant) stays in plain text.
